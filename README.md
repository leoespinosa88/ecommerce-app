# Shop-Worl
 
Tienda online desarrollada con HTML, CSS , Bootstrat 5 y JavaScript vanilla que consume una API REST para mostrar los productos dinamicamente.

## Tecnologias utilizadas

- HTML5 semantico 
- CSS3 
- Bootstrap 5 
- javaScript 
- [DummyJSON API](https://dummyjson.com/products)

## Funcionalidades

- Listado de producto consumidos desde una API externo
- Spinner de carga mientras se obtine los productos
- Mensaje de error si la API falla 
- Diseño responsive con grila de Bootstrap 
- Hover animado en las cards
- Navbar y footer con diseño personalizaso
